# Fahima A — Premium Portfolio

A polished static portfolio built with HTML, CSS and JavaScript.

## Run in PyCharm
1. Extract the ZIP.
2. Open the `Fahima_Portfolio_Premium` folder in PyCharm.
3. Right-click `index.html` → **Open in Browser**.

Optional local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

No `requirements.txt` or `app.py` is needed.
